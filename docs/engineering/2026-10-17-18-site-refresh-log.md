**목표**: 고급스럽되 실제 고객(40~60대, 송파·잠실 실수요자)이 읽기 쉬운 사이트, 방문자 유입과 상담 전환.

**디자인 시스템 (소유자 승인)**
- 글꼴은 Noto Sans KR 하나 (tabular numerals). Playfair/Inter/JetBrains Mono 제거 — 세리프 숫자가 한글 옆에서 어색했음.
- 주요 버튼은 항상 롯데 노랑 `#FFC20E` + 남색 글자 `#13263f`.
- 어두운 영역은 dusk 그라데이션 `--lr-dusk-1/2/3` (`#1b4478 → #23558f → #2c6aa8`), 근흑색 금지. 파란 바탕에 노란 glow 금지(탁한 초록으로 보임).
- 기업 사옥 페이지는 초록 서브브랜드 유지.
- 템플릿 티 제거: 영어 대문자 eyebrow, 장식용 01/02/03, 한 단어 강조 헤드라인, 이모지 아이콘 → 한글 라벨, 선 아이콘.
- 모바일 글자 최소치: 정보 텍스트 12px 이상, 메타 13px, 주소·동의문·검색 제안 14px.
- 모든 색 변경은 `node scripts/contrast_audit.mjs`로 WCAG AA 확인 (열린 위젯·메뉴·검색 결과 같은 상호작용 상태 포함).

**유입 판단 (Search Console/GA4, 2026-10-17 기준)**
- Google: 3개월 노출 약 3.3천, 클릭 41. 리포트는 페이지당 노출이 매우 적음. GA4 14일 활성 사용자 6 (동의 기반이라 과소 집계).

- 리포트 검색 제목은 날짜 대신 질문으로 시작 (페이지 본문 제목은 AGENTS.md 형식대로 날짜 유지).

**매물 운영 판단**
- 매물은 주로 직방·다방에 올리고, 관리자분들은 admin 사이트를 잘 쓰지 않는다 (소유자 설명).
- 따라서 admin 클릭에 의존하는 기능보다 "공개 매물 0건이어도 상담으로 이어지는 화면"을 우선한다.
- 매물별 검색용 정적 페이지는 보류: 최근 확인된 매물이 없고, 거래 끝난 매물이 검색에 남으면 표시·광고 규정상 허위매물 위험. 확인된 매물이 생기면 필수 표시사항 + Legal Bot 검토 후 진행.
- 매물 DB는 삭제하지 않는다. 거래 완료는 `closed_at`으로 숨기고 되돌릴 수 있게 한다.
