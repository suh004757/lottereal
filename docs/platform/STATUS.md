## 2026-11-27 — SDD 개정 5: Phase 1 확정과 리뷰 2회 (Claude)
- 운영 읽기 전용 점검 결과(다른 에이전트, 오너 공유)를 반영했다.
  - 구글 인증은 켜져 있고, 신규 가입은 꺼져 있다.
  - `property-images` 업로드가 일반 로그인 계정에도 허용돼 있다. 이것은 가입 공개의 차단 항목이다.
  - 가입 공개 순서: 무료 조회 → 039 업로드 정책 축소(H6) → 일반 계정 차단 확인 → 신규 가입 켜기(H3).
- 거래완료 표시(`SHOW_COMPLETED`)는 H1 전까지 공개 환경에서 기본 OFF다.
- 중복 게재 배지는 확인된 건(`shared`)에만 붙이고, 재확인 기준은 마지막 확인일이다.
- 1차 리뷰에서 17건을 고쳤다.
  - 가드는 Linux에서만 실행
  - anon 열에 `listing_scope` 추가
  - 탈퇴는 요청 RPC와 Hermes 처리
  - 등급별 확인 문구, "직접 확인" 문구 정리
  - M4가 가입 공개에 의존한다는 점 명시
  - H1·H6 항목 보강, 039 롤백 포함 등
- 2차 리뷰에서 5건을 고쳤다.
  - 제안 문구, 마이그레이션 범위 033~039, 탈퇴 RPC 정의
  - 039 적용 시 가족 계정 업로드가 끊기지 않게 할 것

## 2026-11-27 — SDD 개정 4 (Claude)
- 매물 조회는 로그인 없이 무료로 한다.
- 가입은 구글과 이메일 매직링크로 하고, 로그인 후 기능은 찜, 최근 본 매물, 내 요청 내역이다(`pf_favorites`, `me.html`).
- 30일이 지난 매물도 숨기지 않고 상태로 표시한다.
  - 상태: 확인됨, 재확인 필요, 중복 게시/단독, 거래 완료(회색 도장, 60일)
  - 거래 완료 표시는 `SHOW_COMPLETED` 플래그 뒤에 두고, 부당 표시·광고 해당 여부는 H1에서 확인한다.
- D0-8을 추가했다.
  - 가입을 열면 누구나 `authenticated`가 되므로, 운영 정책을 감사한 뒤에만 가입 화면을 노출한다.
- H3에 구글 OAuth 확인 항목을 더했고, M2 회원가입 화면 단계로 앞당겼다.

## 2026-11-27 — SDD 개정 3 (Claude)
- 주소를 `lottes.co.kr/jamsilsari/`로 정하고, 코드 위치를 `public/jamsilsari/`로 바꿨다. 도메인은 POC 후 구매한다.
- 디자인은 기존 롯데부동산 페이지에 맞추지 않는다. 기존 CSS는 쓰지 않고 독립 설계한다.
- 무인 완주 규칙을 넣었다(§0-8).
  - 게이트와 모순은 해당 항목만 건너뛰고 결정 로그에 적은 뒤 계속 진행한다.
  - 끝나면 아침 보고를 쓴다.
- 비밀값 규칙을 넣었다(§0-7).
  - 비밀값은 발급처에만 보낸다.
  - 커밋 전 gitleaks와 패턴 검사를 하고, CI에도 gitleaks를 추가한다.
  - 유출 시 작업을 중단하고 키를 로테이션한다.
- 운영 DB에 넣은 테스트 매물이 메인 사이트에 노출되지 않게 하는 규칙을 넣었다.
- H3는 Redirect URL에만 추가하도록 바꿨다.
