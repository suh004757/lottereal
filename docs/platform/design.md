# 잠실살이 디자인 기준

개정 2 (2026-11-27, Claude, 오너 승인). M2 첫 구현(크림색 종이, 히어로 금지, 모션 없음)을 대체한다. 이 문서가 화면 판단의 기준이며, 바꾸려면 오너 승인을 받는다.

## 콘셉트: 동네 매물장
동네 중개사무소의 매물장, 볼펜, 인주 도장을 화면 언어로 쓴다. 사이트가 보여 주는 핵심은 "누가, 언제 확인했나"다.
- 강한 요소는 **도장 하나**뿐이다. 나머지는 조용하게 둔다.
- 피할 것: 크림/베이지 바탕과 테라코타 강조, 똑같은 둥근 카드 반복, 대문자 영문 라벨, 숫자 01/02/03 장식, 섹션마다 페이드 인, 버튼 글자에 화살표.

글꼴: 제목·가격 **Hahmlet**, 본문·UI **IBM Plex Sans KR** (Google Fonts, CSP 허용 범위). Pretendard·시스템 고딕 단독 사용으로 되돌리지 않는다.

## 도장 의미 (바꾸지 않는다)
| 확인 등급 | 도장 |
|---|---|
| `site_visit` | 빨간 원형 이중 테두리 "임장 확인 MM.DD" |
| `owner_listed` / `tenant_listed` | 파란 볼펜 사각 "소유자 의뢰" / "임차인 의뢰" |
| 재확인 필요(`needsReview`) | 회색 `.old` 도장 |

- 도장은 `aria-hidden`이다. 같은 사실을 태그와 "마지막 확인 11월 26일, N일 전" 줄에 글자로 반드시 함께 쓴다.
- 현장 확인을 하지 않은 매물에 "직접 확인", "다녀온 매물만" 같은 문구나 빨간 도장을 쓰지 않는다.

## 화면
- **첫 화면:** 석촌호수 벚꽃 사진(`img/bg-img/slide1.jpg`) 위에 아래로 짙어지는 남색 그라데이션을 깐다. 제목은 "잠실에서 살 집, 누가 언제 확인했는지 적어 둡니다"이고 버튼은 매물 보기, 전화로 말하기 두 개다. 오른쪽 아래에 가장 최근 확인 날짜를 빨간 도장으로 찍는다. 움직임은 이 도장이 한 번 찍히는 것 하나뿐이고, `prefers-reduced-motion: no-preference`일 때만 실행한다.
- **목록:** 카드 그리드가 아니라 장부 한 줄이다.
  - 넓은 화면(44rem 이상): 사진 15rem | 거래 유형·동, 제목, 가격, 확인 날짜, 태그 | 도장·찜.
  - 모바일: 사진이 위에 오고 도장은 사진 오른쪽 위에 둔다.
  - 거래 유형은 가로 스크롤 칩이다. 동, 확인 방식, 최대 가격은 접힌 보조 필터다.
- **매물이 없을 때:** "매물장을 채우는 중입니다"와 전화로 조건 말하기, 집 내놓기 버튼을 두고, 그 아래에 단지별 실거래 바로가기 타일을 둔다. 필터 결과가 없을 때는 조건을 바꾸라는 안내만 한다.
- **상세:** 목록으로 → 거래 유형·가격·확인 날짜·태그 옆에 도장 → 사진 | 남색 문의 박스, 월 실부담, 동네 자료 순서다. 넓은 화면에서는 오른쪽 열이 따라 내려온다.
- **공통:** 메뉴는 매물 찾기 / 찜한 매물 / 집 내놓기다. 브랜드 앞에 "잠실" 두 줄 빨간 도장을 둔다. 푸터는 남색 법정 표시 영역이다.

## 품질 하한
- 대비 WCAG AA. 측정값: ink 15.7, muted 6.13, muted on lake 5.47, pen 8.54, seal 5.58, warn 6.65, footer 10.2. `.old` 도장 3.71은 장식(`aria-hidden`)이라 예외다.
- 360/390/768/1440px에서 가로 넘침이 없어야 한다. 키보드 포커스가 보여야 하고, 주요 조작 영역은 44px 이상이다.
- 결과 없음, 검색 결과 없음, 조회 실패, 기기 저장 실패를 각각 다르게 보여 준다. 로그인과 지도는 운영 조건이 검증될 때까지 숨긴다.
- 테스트 고정 항목: noindex, CSP, 법정 표시, "보증" 금지("보증금" 제외), 기능 스위치 OFF.
